# 🚀 LOCAL DEVELOPMENT

To run this project locally, first check the frontend folder and its `package.json` file.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Vikash-malviya/Portfolio-DataAnalyst.git
```

### 2️⃣ Enter the frontend directory

```bash
cd Portfolio-DataAnalyst/frontend
```

### 3️⃣ Install dependencies

Use the package manager matching the existing lockfile.

For npm projects:

```bash
npm install
```

### 4️⃣ Start the development server

Check the scripts in `package.json`. If a `dev` script exists:

```bash
npm run dev
```

Follow the local URL printed in the terminal.
